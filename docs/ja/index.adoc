= mcp-servers: 自分用の MCP サーバー集

AI エージェント (主に Claude Code) に渡す MCP サーバーを集めた pnpm の monorepo。
文書の管理、作業計画、コードやドキュメントの構造的な読み書き、図の描画、データの読み取り、他の MCP サーバーへの関所 (firewall) などを、それぞれ独立したサーバーとして持つ。

[cols="1,3",options="header"]
|===
|項目 |内容
|構成 |`+packages/*+` に 25 パッケージ (MCP サーバー 15、共有ライブラリ 10。サーバーのうち 2 つは Python で Docker 配布)
|言語 |TypeScript (Node.js 22.13 以上、pnpm 11)。`+graph-math-mcp+` と `+python-diagrams-mcp+` だけ Python
|サーバーの形 |多くのサーバーが `+describe+` と `+execute+` の 2 つのツールに操作をまとめる (xref:architecture.adoc[])
|安全の考え方 |AI ツールの承認プロンプトに頼らず、サーバー側で止める (xref:approval.adoc[])
|配布 |npm (OIDC の Trusted Publishing)、ghcr.io (Docker)、GitHub Packages (試し用)。ほとんどは `+private: true+` で公開しない (xref:ci-release.adoc[])
|開発時の起動 |`+.mcp.json+` から `+npx tsx ./packages/<name>/src/index.ts+` でソースのまま動かす (xref:dev-loop.adoc[])
|===

[[layout]]
== ディレクトリ構成

[cols="2,4",options="header"]
|===
|パス |中身
|`+packages/*/+` |各パッケージ。サーバーは `+src/index.ts+` が入口で、`+src/__tests__/+` にテスト
|`+docs/+` |エージェント向けの規約の文書 (Markdown)。`+interactive-instruction-mcp+` が読み書きする (xref:dev-loop.adoc#corpus[規約の文書])
|`+docs/ja/+` |このドキュメント (AsciiDoc)。`+.adoc+` は `+interactive-instruction-mcp+` から見えない
|`+docs-site/+` |このドキュメントを Antora でサイトにする道具 (xref:docs-site.adoc[])
|`+scripts/+` |repo の道具 (`+mcp-session.mjs+`、CI のテスト matrix、bundle と changelog の検査)。これも workspace の 1 パッケージ
|`+eslint-rules/+` |独自の lint ルール (oxlint から読む)
|`+.github/workflows/+` |CI、npm / Docker / GitHub Packages への公開、workflow の lint、docs site
|`+.changeset/+` |Changesets の設定と、まだ version に反映されていない変更の記録
|`+.claude/+` |Claude Code の設定と SessionStart hook (クラウドのセッションで install と build をする)
|`+.mcp.json+` |この repo で作業するときに使う MCP サーバーの登録 (ソースから起動)
|`+compose.yaml+` |テスト用の AWS エミュレーター (floci)
|===

[[principles]]
== 共通の決まり

`+docs/policy.md+` 以下にある、どのサーバーも従う決まりのうち、構造に効くものをまとめる。

[cols="1,3",options="header"]
|===
|決まり |中身
|ツールの schema に引数を書かない |`+inputSchema+` は `+z.object({}).passthrough()+`。引数の説明は `+describe+` ツールが返す (xref:architecture.adoc#tool-surface[ツールの見せ方])
|承認プロンプトは制御ではない |止めたい操作は、許可リストに載らない別のツールにするか、変更内容に紐づく token で止める (xref:approval.adoc[])
|環境から読める値は設定にする |閾値などは環境変数で変えられるようにし、議論で決めない (`+IIMCP_LINT_MAX_LINES+` など)
|ミスはなるべく高い段で防ぐ |型 → lint → 独自 lint → テスト → 文書のルール、の順に、表せる一番上で防ぐ
|カバレッジ 95% 以上 |テストは repo の中の fixture だけを使う
|===
