# グラフ構造の図示を共通ライブラリ化

## 背景

本 monorepo の複数の MCP サーバーは、それぞれ「ノードとエッジ」で表現できるグラフ構造を内部に持っている。

| サーバー | ノード | エッジ |
|---|---|---|
| interactive-instruction-mcp | ドキュメント | `relatedDocs` によるトピック間の関連 |
| traceable-chain-mcp | requirement/spec/design/adr | `requires` による依存 |
| ast-typescript-mcp | モジュール・シンボル | import / 参照関係 |
| interactive-pdca-mcp | タスク | `dependencies` |

いずれも現状は文字列（リストや箇条書き）でしか提示できておらず、関連の全体像が掴めない。

## 要求

これらのグラフ構造を **図として提示できる** ようにする。ただし、

- 各サーバーが個別に描画ロジックを持つのは DRY 違反であり、品質もばらつく
- 一方で「何を図示するか」はドメイン固有の知識であり、共通化できない

したがって、**責務を分離した共通ライブラリ**を提供する。

## 責務分離（本要求の中核）

- **呼び出し側（各 MCP サーバー）の責務**: 自ドメインのデータを「ノードとエッジ」に落とすこと
- **共通ライブラリの責務**: ノードとエッジを受け取ったら、レイアウト計算して図にすること。それだけ

共通ライブラリはドメイン知識を一切持たない。`relatedDocs` も `requires` も知らない。

## 受け入れ条件

- 呼び出し側が `{ nodes, edges }` を渡すだけで図が得られる
- 呼び出し側がレイアウトアルゴリズム・座標計算・描画のコードを一切書かなくてよい
- ライブラリに特定 MCP サーバー固有の型・語彙が混入していない
