## 設計を作り直した経緯

**初版は「headless でレイアウト → SVG を自前生成」という構成で実装を完了していた**（1,899 行 + テスト 1,517 行、カバレッジ 99.6%）。動作もしていた。それを破棄して現在の HTML 専用構成に作り直している。

理由は、初期要件が「人間がグラフィカルに見たい」であり、それにはページで足りたため。静的 SVG のために払っていたコストは:

- `svg/geometry.ts`（境界クリップ・矢印・自己ループ・平行辺）211 行
- `svg/render.ts`（SVG 生成）306 行
- `measure.ts`（canvas がないためのラベル幅推定）225 行
- 対応するテスト 686 行

`measure.ts` が必要だったのは、**headless には canvas がなく文字幅を測れない**ため。ブラウザに任せればこの問題自体が消える。

この判断はユーザーの「html を生成してくれるというだけでも別に良かった」という指摘で確定した。計画段階で「出力3形式は全部入れる、パラメータ化できるので議論しない」と決めていたのが誤りで、出力形式を1つ増やすのは設定値ではなく 700 行超の実装だった。実装量が大きく変わる分岐を「パラメータだから」と片付けてしまっていた。

### 破棄した実装から得た知見（headless 特有の落とし穴）

現構成では不要になったが、headless で cytoscape を使う場合には有効。

| 落とし穴 | 症状 |
|---|---|
| `cy.width()/height()` が headless で 0 | `breadthfirst` の座標が `a(-4.375e+49, 0)` になる。`boundingBox` の明示で解消 |
| cytoscape は結果を `boundingBox` にリスケールする | dagre / cose に渡すと計算済みの間隔が上書きされノードが重なる。**面積ベースのレイアウトにのみ渡す** |
| 要素定義の `position` が読み戻されない | `preset` が全ノードを原点に積む。`positions` オプションで直接渡す |
| cytoscape インスタンスがハンドルを保持 | `cy.destroy()` を呼ばないと Node プロセスが終了しない |

2番目は実データを描画して初めて発覚した。実測（孤立ノード6件、dagre LR）:

| | y 座標 |
|---|---|
| boundingBox あり | 0, 133, 267, 400, 533, 667 — 800 を正確に6等分（＝リスケール）。高さ56のノードが重なる |
| boundingBox なし | 19, 106, 193, 280, 367, 454 — 87px 間隔。`nodeSep` が生きている |

3番目は現構成でも該当するため、`preset` の座標は `positions` で渡している。

| 確認項目 | 結果 |
