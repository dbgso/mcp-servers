## 背景

ウォーターフォールは人間には制限だが、AIには適切なガイドライン。

## 要求

- requirement → spec → design の順序を強制
- AIがサボらないための手段として機能
- ルールが決まっていればAIは高速にこなす

## 期待効果

- 依存関係の自動検証でドキュメント孤立を防止
- 作業開始前に必須リンクを強制、全体構造を明確化
- trace操作で影響範囲を即座に可視化
