## コンポーネント構成

```
src/
  index.ts          # エントリポイント、CLI引数処理
  server.ts         # MCPサーバー設定
  chain-manager.ts  # ビジネスロジック
  types.ts          # Zodスキーマ、型定義
  storage/
    markdown-storage.ts  # ファイルシステム操作
  operations/
    query-ops.ts    # read, list, trace, validate
    mutate-ops.ts   # create, update, delete, link
    registry.ts     # 操作レジストリ
  tools/
    handlers/       # MCPツールハンドラ
```

## データフロー

```
MCP Tool Call
    ↓
ToolHandler (query/mutate)
    ↓
Operation (read/create/etc)
    ↓
ChainManager (バリデーション)
    ↓
MarkdownStorage (ファイルI/O)
```

## 設計判断

- **ULID使用**: ソート可能なユニークID
- **Markdown+YAML**: 人間が読み書き可能
- **タイプ別ディレクトリ**: `docs/chain/{type}/{id}.md`
